FORGE — Living Games

Interactive 3D

A browser platform for discovering, building, publishing and playing collaborative 3D adventure worlds and battle chess.

Repository overview

- React application, generated cover art, responsive Discover, profiles, search and bookmarks. - Actual Three.js low-poly world rendering, 12 reusable object types, drag placement, object manipulation, transform/material controls and deterministic visual rules. - Local email/password accounts using scrypt password hashing; HTTP-only, SameSite session cookies; seven-day sessions; server-side project roles; basic login throttling and mutation-origin checks. - SQLite persistence for accounts, avatars, projects, memberships, bookmarks and published snapshots. - WebSocket collaboration with presence, cursor indicators, saved-state broadcasts and optimistic revision checks. - Server-authoritative multiplayer crystal collection, bounded movement, basic cottage/rock collision checks, shared win state, private draft playtesting and session invite links. - Project JSON export and a searchable build guide. - No model calls in editing, saving, publishing, avatars, or playing.
