Funnels — Build, Publish & Measure

SaaS Platform

A production-minded funnel platform with visual page building, publishing, analytics, leads, orders and custom-domain workflows.

Repository overview

Build, publish and measure marketing funnels: a drag-and-drop page builder on GrapesJS, templates, custom domains with DNS verification, public serving, analytics, leads and orders, signed webhooks and AI assistance. TypeScript, Hono, SQLite or PostgreSQL, React 19, Tailwind. More screens, light and dark, at three sizes: docs/design/DESIGN.md. Every page and control is described in the user guide; how each feature works end to end in docs/FEATURES.md; the code map, data model and jobs in docs/FUNCTIONS.md; the full documentation index is docs/README.md.

Documented architecture and workflow

Funnels is one Node process (Hono on SQLite by default, or PostgreSQL) that serves the JSON API, the built React app, published funnel pages (by Host header and on built-in /s/... addresses) and signed previews. An in-process worker drains a database-backed job queue. Funnels can also be published as static sites to Cloudflare Pages, and an optional Cloudflare Worker can sit in front. The code map, jobs, route groups and the full data model are in FUNCTIONS.md.
