ShopFlow — Realtime Ecommerce Platform

Commerce Platform

A multi-surface ecommerce system spanning shopper, admin, rider and conversational ordering, with live tracking, subscriptions and hybrid recommendations.

Repository overview

A full-stack, production-ready ecommerce platform handling 5,000 orders/day with 100,000 concurrent users .

Project features

  • 4 Panels : Shopper, Admin, Rider, AI Chat (order via conversation)
  • Payments : Google Pay, Card (Stripe), Cash on Delivery, Wallet
  • AI Recommendations : Region-based + collaborative filtering + purchase history
  • Real-time : WebSocket for live order tracking + rider location
  • Auth : Google OAuth 2.0 + OTP (Twilio)
  • Subscriptions : Monthly/weekly auto-delivery with discounts
  • Scheduled Delivery : Pick date & time at checkout

Architecture inferred from repository structure

The implementation is centered on JavaScript, React, Node.js, Express, PostgreSQL. The repository is organized into backend, frontend, mobile, recommendation-engine areas. Delivery and dependency evidence includes Docker, Docker Compose, Node package manifest, Python requirements.
