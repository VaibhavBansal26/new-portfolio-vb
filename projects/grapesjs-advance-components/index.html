Grapesjs Advance Components

Package & Extension

Grapesjs Advance Components is a Package & Extension project by Vaibhav Bansal built with Npm package using react js , grapesjs.

Repository overview

- promptsite , a command line tool. It writes a multi-page site from one sentence with your own model, lets you polish it in a visual editor, audits it for leaked secrets , and deploys it to Cloudflare Pages or Netlify. - grapesjs-advance-components , a GrapesJS plugin with 41 accessible, themeable blocks (pricing, testimonials, team, tabs, forms that submit, Stripe checkout and more), defineComponent for your own blocks, and multi-page export. A real recording using the offline --provider mock , so no API key is needed. With a key, your model writes the copy.
