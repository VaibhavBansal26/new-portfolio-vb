DevSecOps - App Deployment Full Pipeline

DevOps

DevSecOps - App Deployment Full Pipeline is a DevOps project by Vaibhav Bansal built with Amazon EKS,Prometheus, Grafana, Helm, Jenkins, Docker, Kubernetes, AWS, DevSecOps, SonarQube, Owasp, Trivy.

Repository overview

1. GitHub → Jenkins → SonarQube → Docker Build : Code is pulled from GitHub, built by Jenkins, analyzed by SonarQube, and containerized via Docker. 2. Argo CD, Helm, and EKS : Argo CD (GitOps) or Helm charts are used to deploy and manage your application on Amazon EKS.
