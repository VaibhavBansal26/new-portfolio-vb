Conversations — Unified Customer Inbox

Realtime SaaS

A unified live-chat, SMS and email workspace with team routing, AI assistance, browser calls, billing, permissions and a scale-out realtime architecture.

Repository overview

- Inbox : live chat widget, SMS (Twilio) and email (SendGrid) in one place; inboxes with round-robin routing, notes and @mentions, snooze, templates, notifications (in-app, email, Web Push), CSAT, copies of a conversation by email, optional AI assistance. - Support automation : tickets, departments and routing, AI support agents in the chat and on SMS and email, visitor details and pre-chat custom fields (docs/AI-AGENTS.md). - Calls : browser voice and video with visitors, phone calls, calls with the AI assistant (optionally with a photoreal avatar), teammate and group calls, call links (docs/CALLS.md). All off by default; nothing is recorded. - Team chat : channels (public or private), direct and group messages, threads, reactions, pins, search, shared customer-conversation cards (docs/TEAM-CHAT.md). - Channels you connect yourself : each workspace pastes its own Twilio and SendGrid credentials and is told plainly when a channel is in test mode (docs/CHANNELS.md); the chat widget has a guided install and an in-app preview (docs/WIDGET.md). - Access : 38 permissions, four built-in roles plus custom roles, two-factor, invitations, audit log (docs/RBAC.md). - Money : plans, prepaid c

Documented architecture and workflow

Conversations is a unified customer inbox: live chat (embeddable widget), SMS (Twilio) and email (SendGrid) land in one inbox that a team works together. It is a standalone product with its own auth, tenancy, contacts, jobs and AI; it knows nothing about any other application. - Server: Node = 22.13, TypeScript (strict), Hono + @hono/node-server , Socket.IO 4 on the same HTTP server , built-in node:sqlite (WAL, foreign keys), zod , jose . - Web: React 19, Vite, react-router, TanStack Query, plain CSS. - One process serves the REST API, the Socket.IO namespaces, the widget script, the built web app and the background scheduler.
