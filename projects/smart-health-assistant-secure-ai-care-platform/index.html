Smart Health Assistant — Secure AI Care Platform

Healthcare AI Platform

Smart Health Assistant — Secure AI Care Platform is a Healthcare AI Platform project by Vaibhav Bansal built with Angular, Spring Boot, Java 21, Python, FastAPI, Machine Learning, Claude, SSE, Healthcare Security, Explainable AI.

Repository overview

Angular + Spring Boot + ML healthcare app: login and roles (patient / doctor), appointment booking, an ML doctor recommender , a streaming AI health chat (Claude), and a diabetes risk check . Educational project, not a medical device: nothing here is a diagnosis.
