Heart Disease Prediction using Generative AI, Streamlit, OpenAI

Machine Learning

An interactive health-risk prediction workflow combining a trained machine-learning model with Streamlit and generative AI guidance.

Repository overview

Heart-risk estimate + personalised next steps from a hybrid content / collaborative recommender.

Project features

  • Risk model — predicts a heart-disease risk score from 11 clinical inputs. Candidates (each in one sklearn Pipeline , imputation fitted inside CV folds): logistic regression, gradient boosting and a PyTorch MLP .
  • Hybrid recommender — ranks 13 lifestyle / screening / clinical interventions:
  • Content-based: patient needs (lipids, BP, glucose, fitness, metabolic, cardiac work-up) matched to each intervention's target vector.
  • Collaborative: a PyTorch two-tower model. The patient tower is an MLP on features plus the mean embedding of interventions the patient already liked; the item tower is an id embedding plus content features. It handles cold start (features only) and warm start (liked items).
  • Hybrid: α·content + (1-α)·collaborative , with α tuned on a validation split. A safety rule always surfaces a cardiology referral at high scores.
  • Education links from the NIH/NLM MedlinePlus web service (free, no key).
  • MLflow experiment tracking and model registry, browsable from the app's 🧪 MLflow tab.
