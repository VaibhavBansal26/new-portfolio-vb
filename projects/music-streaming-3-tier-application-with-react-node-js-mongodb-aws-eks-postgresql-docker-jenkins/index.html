Music Streaming 3-Tier Application with React, Node JS, MongoDB, AWS EKS, PostgresQL, Docker, Jenkins

MERN

Music Streaming 3-Tier Application with React, Node JS, MongoDB, AWS EKS, PostgresQL, Docker, Jenkins is a MERN project by Vaibhav Bansal built with AWS EC2, AWS S3, React, Node Js, Express, MongoDB, PostgreSQL, Docker, Nginx, Redis, Kubernetes, AWS EKS, Docker, Docker Compose, Jenkins, Sonarqube, Neon db.

Repository overview

A microservice-based music streaming app: a React frontend plus three Node/TypeScript services, containerised with Docker and deployed to AWS EKS through a Jenkins pipeline.

Project features

  • Admin
  • Album
  • Home
  • Login
  • Play List
  • Register
  • Music Streaming Application

Documented architecture and workflow

Service Port Responsibility Storage --- --- --- --- userService 5001 Register / login (JWT), profile, playlist toggle MongoDB songService 5003 Read-only albums and songs, Redis-cached PostgreSQL (Neon), Redis adminService 5002 Admin-only album/song upload and delete, cache invalidation PostgreSQL (Neon), Redis, Cloudinary frontend 80 React + Vite + Tailwind SPA served by nginx none adminService authenticates requests by calling userService GET /api/v1/user/getUserProfile with the caller's token header.
